# Unlocking Behavioral Intelligence in Airline Loyalty Programs

A group analytics project focused on spotting airline loyalty members whose engagement may decline, understanding which members are most valuable, and identifying ways to improve retention.

The project uses historical loyalty-member and flight-activity patterns to frame churn prediction and customer segmentation, with the aim of turning analysis into clear retention actions for marketing teams.

This repository contains a project overview. The group's supporting analysis files and data are not included.
